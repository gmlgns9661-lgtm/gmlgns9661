🚇 출근길 자리전쟁 3D

4개 노선 · 개찰구 → 자리 쟁탈 · 출근길 2스테이지

스테이지

1️⃣개찰구 → 승강장: 카드 찍고 계단 내려가서 스크린도어 앞 줄서기. 열차가 꽉 차서 못 타면 지각 = 실패. 앞쪽으로 탈수록 2스테이지를 객차 안쪽에서 시작
2️⃣자리 쟁탈전: 선릉 도착 전에 앉아라!

조작

🕹️폰: 왼쪽 아래 조이스틱으로 이동, 오른쪽 큰 버튼 = 행동
⌨️PC: WASD/방향키 이동 · Space 행동 · Q 가방 · F 폰
💳개찰구 단말기 앞에서 행동 버튼 = 카드 찍기 (폰 보기 중이면 모바일 카드로 바로!)
🪑빈자리 앞에 서서 행동 버튼 = 앉기
💪사람 쪽으로 계속 밀면 비집고 들어감

🔒지퍼 잠금

👀 창밖 보기 = 다음다음 역일 수도, 낚시일 수도

🎒 가방

🔙뒤로 메기: 비집기 빠름, 대신 40% 확률로 가방이 걸림 → 행동 버튼 연타로 빼기. 개찰구에선 카드 꺼내려면 가방 뒤지기 연타
🔜앞으로 메기: 비집기 느림, 걸리지 않음 · 매너↑ → 길이 잘 열림
📱폰 집중(F): 불쾌지수가 천천히 오름 + 환승·하차 정보. 대신 시야가 좁고 걸음이 느림
🎧이어폰(R): 불쾌지수 절반만 오름(노캔 이어폰이면 더 느리게). 대신 안내방송·빌런 경보가 안 들림

🚨 빌런 경보

🟡쩍벌 대마왕: 옆자리까지 차지 → 앞에서 🔨 뿅망치 3번
🟠전설의 투척러: 가방 던져 자리 예약 → 닿기 전에 앉기 또는 던지기 전에 옆에서 🔨 뿅망치
🔴황금 돌격 할아범: 한 줄 돌진 → 빨간 줄에서 피하기 또는 돌진 전에 옆에서 🔨 뿅망치
🟠개찰구 수색대장 (1스테이지): 개찰구 막고 카드 찾기 → 옆 개찰구로 or 🔨 뿅망치 3번
🔴환승 질주러 (1스테이지): 대합실 가로 질주 → 빨간 줄에서 피하기
🟠끼어들기 장인 (승강장): 아무 줄(내 줄 포함)에 새치기 → 옆에서 🔨 뿅망치 3번
🟠캐리어 폭주족 (1스테이지): 캐리어에 발등 찍히면 기절 · 개찰구에 끼면 한동안 막힘
🟡악기 마스터: 노란 원 안 불쾌지수↑ → 옆에서 🔨 뿅망치 4번
🟡도시락 빌런: 초록 원 안 불쾌지수↑ → 옆에서 🔨 뿅망치 3번
🟡통화 데시벨러: 앉아 있던 승객이 갑자기 스피커폰 통화! 분홍 원 안 불쾌지수↑ (앉아 있어도) → 옆에서 🔨 뿅망치 3번
🔨새치기 응징: 내 앞 빈자리를 남이 가로채면 3초 안에 행동 = 뿅! 자리 탈환
🟡볼륨 만렙러: 보라색 원 안에서 불쾌지수↑ → 옆에서 🔨 뿅망치 3번
🟠백팩 회전술사: 빨간 원 경고 후 회전 → 피한 뒤 어지러워할 때 🔨 뿅망치 1방

😤 불쾌지수

📈출근길이라 30에서 시작. 사람과 닿을수록·서 있을수록·빌런에게 당할수록 올라감 → 100이 되면 😵 출근 중 쓰러짐 = 실패
🔨옆 사람 불쾌지수가 100이면 싸움 → 뿅망치 미니게임. 끝나면 내 불쾌지수 +50
🪑앉으면 불쾌지수 -30, 이후 빨리감기 ⏩로 편하게 감
🚪도착역(환승역)에선 문이 열린 동안 직접 "내리기"를 눌러야 함. 놓치면 😱 지나쳐서 되돌아감: -300점, 불쾌지수 +25. 🎧 이어폰 중엔 도착 방송·차임이 안 들려요!
🧍개찰구·승강장은 발자국 줄 끝에 서기. 줄 앞이나 중간에 끼어들면 주변 사람 불쾌지수↑ (머리 위 😒😠🤬)
🤰임산부 배려석(분홍)은 임산부만! 앉으면 주변 시선 폭발 = 실패. 임산부도 탔다 내렸다 해요
👵앉아 있을 때 어르신·임산부가 내 앞에 오면 양보(매너·점수↑, 대신 서서 감) 또는 자는 척(헛기침에 움찔하면 들킴!). 옆 사람이 어깨에 기대 졸기도 해요
📉아무와도 안 닿으면 천천히 내려감 · 빌런 참교육 성공 시 -15 · 📱폰 보기 중엔 덜 오름
☕대합실 아이템: ☕ 커피(-30) · 🎧 노캔 이어폰(볼륨 빌런 무효) · 🍬 목캔디(-15)
