# 스틱 액션 디펜스 — 인트로 (15초)

- `index.html` — 브라우저에서 바로 열리는 인트로(캔버스 애니메이션 + 합성 효과음). 외부 이미지/사운드 파일 없음.
  - 우측 상단 **SKIP** 버튼(진행률 링 표시) / `Esc` 키로 건너뛰기 → 타이틀 화면으로 바로 이동
  - 15초 후 또는 SKIP 시 **▶ 게임 시작** 버튼 노출 (`Enter`/`Space` 로도 시작)
  - 좌측 하단 사운드 토글 (브라우저 자동재생 정책 때문에 기본은 음소거)
  - 게임과 연결: `index.html` 상단 `CONFIG.NEXT_URL` 에 게임 주소 입력. 또는 `intro:end` / `intro:start` 이벤트(iframe이면 `postMessage`)를 받아 처리
- `intro.mp4` — 같은 인트로를 1280×720 / 30fps 로 렌더링한 영상 (SNS·스토어 홍보용)
- `render-video.mjs` — 영상 재생성 스크립트 (`node render-video.mjs [출력경로] [fps]`, playwright + ffmpeg 필요)

## 구성 (타임라인)
| 시간 | 장면 |
|---|---|
| 0–2.6s | 암흑 속 "평화는 끝났다", 지평선에 붉은 눈들 |
| 2.6–5.3s | 노을 아래 성벽, 끝없이 몰려오는 적 무리, 포탑 사격 |
| 5.3–9.6s | 영웅 도약 착지 → 대시 베기 콤보, 슬로모션 띄우기, 회전 베기 |
| 9.6–12s | WAVE 100 보스 등장, 기 모으기 → 일격에 보스 절단 (LIMIT BREAK) |
| 12–15s | 타이틀 로고 슬램 + "최후의 방어선을 지켜라" + 게임 시작 버튼 |
